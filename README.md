## 📦 Adding New Backend Services

When you need to add additional backend services (e.g., API server, database service, auth service), follow these steps:

### Step 1: Create the Backend Structure
```bash
# Create new backend directory
mkdir -p apps/backend/[service-name]
cd apps/backend/[service-name]

# Initialize package.json
pnpm init
```

### Step 2: Configure package.json
```json
{
  "name": "[service-name]",
  "version": "1.0.0",
  "private": true,
  "scripts": {
    "dev": "[your-dev-command]",
    "build": "[your-build-command]",
    "start": "[your-start-command]",
    "lint": "eslint src --ext .ts"
  },
  "dependencies": {
    // Your runtime dependencies
  },
  "devDependencies": {
    "typescript": "^5",
    "@types/node": "^20",
    "tsx": "^4",
    // Other dev dependencies
  }
}
```

### Step 3: Update Workspace Configuration
Add your new backend to `pnpm-workspace.yaml`:

```yaml
# pnpm-workspace.yaml
packages:
  - "apps/*"
  - "apps/backend/socketio"
  - "apps/backend/[service-name]"    # ← Add this line
  - "packages/*"
  - "packages/phaser-games/wildstrikes"
```

### Step 4: Reinstall Dependencies
```bash
# From root directory
pnpm install
```

### Step 5: Verify Integration
```bash
# Test that your service is detected
pnpm turbo run dev --parallel
```

Your new service should now be included in the parallel execution!

### Example: Adding an API Server
```bash
# 1. Create structure
mkdir -p apps/backend/api
cd apps/backend/api

# 2. Initialize with Express
pnpm init
pnpm add express cors helmet morgan
pnpm add -D @types/express @types/cors @types/morgan typescript tsx

# 3. Create src/index.ts
# 4. Add to pnpm-workspace.yaml
# 5. Run pnpm install from root
# 6. Test with pnpm dev
```

## 🆘 Troubleshooting

<div align="center">

### 🔧 **Common Issues & Quick Fixes** 🔧

</div>

<details>
<summary><strong>📦 Dependencies Not Installing</strong></summary>

```bash
# 🧹 Clear cache and reinstall
pnpm store prune
rm -rf node_modules
rm pnpm-lock.yaml
pnpm install
```

</details>

<details>
<summary><strong>🔌 Backend Not Starting with Turbo</strong></summary>

1. ✅ Check if backend is in `pnpm-workspace.yaml`
2. ✅ Verify `package.json` has a `dev` script
3. ✅ Run `pnpm install` after adding new packages

</details>

<details>
<summary><strong>🚦 Port Conflicts</strong></summary>

```bash
# 🔍 Check what's using a port (Linux/macOS)
lsof -i :3000

# 💀 Kill process if needed
kill -9 [PID]
```

</details>

<details>
<summary><strong>🔍 ESLint Issues</strong></summary>

```bash
# 🔄 Update ESLint configuration
pnpm add -D eslint@^9 @typescript-eslint/eslint-plugin@^8
```

</details>
